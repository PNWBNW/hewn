## 2026-11-25 — The desktop workflow builds the web bundle once, on Linux, and the other systems only package it

The desktop app's Windows and macOS jobs each built the web bundle themselves, and failed: Windows's
`cmd.exe` can't run the build script's `HEWN_STATIC=1`, and four screens sit beside a module whose name
differs only by case, which macOS and Windows can't tell apart. Rather than reshape the web code for
the desktop (#392, closed; Joshua, 2026-11-25: the desktop builds have their own rails), the workflow
now has a `bundle` job that builds `apps/business/out` once on Ubuntu 24.04 and uploads it with a
SHA-256 list of every file; the installer jobs download it, check every file against the list (a
changed, extra or missing file fails the job), and package it. Every installer now carries the same
bytes. No web file changes. The check was tried on a sample bundle here: the good copy passes, a
changed file fails.
