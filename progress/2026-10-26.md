## 2026-10-26 — A link checker for the documents (ICM Step 7, part 1)

`scripts/check_links.py` (standard library, `python3 -I`; a CI step here, and the same file in
`pnw_mvp_v2`'s plan gate) fails when a link in a tracked Markdown file points at a file that
isn't there, or names a heading the target doesn't have (anchors made the way GitHub makes them,
inline code kept; explicit `<a id>` counts). It reads inline links, reference definitions and HTML
`href`/`src`, and skips web links (a network check would fail on someone else's outage), links into
a submodule, anything in code, and the history (`archive/`, `progress/`, and the archives in
`pnw_mvp_v2`). Shown failing on planted links (a missing file, a missing heading in another file
and in the same one, an HTML link, a reference definition) and ignoring the ones it should (in a
fence, in inline code, a web link, into the submodule).

It found one real break: the README's "Next: mainnet" still pointed at the build plan's Mainnet
names section, which moved to `docs/MAINNET_NAMES.md` yesterday; fixed. Hewn: 285 links in 37
documents; `pnw_mvp_v2`: 39 in 35.
